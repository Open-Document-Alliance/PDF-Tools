# Rotated text-run spacing

This repair preserves source-backed word boundaries when a page is rotated
180 degrees. It does not recognize images, guess words, or reconstruct rotated
paragraphs.

## Reproduction and cause

A generated PDF places `Alpha` and `Beta` in separate font runs with a four-point
gap. PDF.js retains both runs and a whitespace item. At zero degrees, the layout
and Markdown contain `Alpha Beta`; at 180 degrees the previous implementation
produces `AlphaBeta`. The same failure occurs with an offset CropBox and a
UserUnit of two.

Line reconstruction omits standalone whitespace items and measures the gap
between neighboring non-whitespace runs. That measurement previously used only
the viewport's horizontal bounding-box coordinates. On a half-turned page the
source text advance points left, so the formula interpreted a real positive
space as an overlap.

The repair projects the neighboring run edges onto the source-bound quad's
anchor-to-terminal direction when both advances are nondegenerate and
co-directed. RTL uses the opposite pair of bordering edges. The existing
spacing thresholds and fallback for degenerate or differently oriented runs
are unchanged. Raw items, source order, line grouping, and page geometry are
unchanged.

## Regression boundary

The real-PDF bank covers all four right-angle page rotations, ordinary and
offset CropBox/UserUnit geometry, and positive, touching, and overlapping gaps.
It compares source and share outputs, independently replays layout evidence
against the generated bytes, and checks the rendered Markdown body. Both
mirrors use the same pinned PDF.js standard-font assets during the test.

Two additional mocked-parser cases cover inverted LTR and RTL runs without
standalone whitespace items, with positive, touching, and overlapping gaps.
Restoring only the old horizontal gap formula fails exactly the two real-PDF
180-degree positive-gap cases; the other 22 real-PDF cases stay green.

Quarter-turn pages keep the existing conservative source-order line breaks.
No broader reading-order, multilingual segmentation, OCR, or benchmark-quality
claim follows from these checks. The source-bound extraction oracle is
regenerated through its existing generator; only the layout module's size and
hash and the aggregate validator-source fingerprint change, not its expected
document results.
