# PDF Tools v0.14.0 release candidate

Status: release preparation complete. This record is not publication authority.

## Scope

Version 0.14.0 is the first release candidate after v0.13.0. It combines:

- an optional Lumin e-signing workflow with browser-based account connection,
  exact local recipient preview, fresh confirmation before upload, durable
  operation records, status polling, and fail-closed artifact download;
- more reliable deterministic extraction for invisible text layers, rotated
  text spacing, segmented and captioned tables, page furniture, mathematical
  gaps, XFA documents, and malformed inputs;
- more explicit `compare_pdfs` coverage and ambiguity reporting;
- dual-era MCP compatibility, native MCP Skills discovery, a portable PDF
  workflow Skill, and the remote stateless MCP profile now present on main;
  and
- packaging, process-containment, licensing, and source-identity hardening.

PDF Tools remains local-first. It contacts Lumin only when a Lumin tool is
called, and it sends a prepared PDF only after the user confirms the exact
request. The package does not include OCR and this release makes no public
claim of superiority over Databricks, Firecrawl, or another product.
