# PDF Tools v0.15.0 release candidate

Status: release preparation complete. Independent review returned ship-after-fixes; the fixes are applied below.

## Scope

Version 0.15.0 is the first release after v0.14.0 (2026-09-22). It ships the work merged to master from #205 through #233, plus the dependency advisory fix in #236:

- private local password entry for encrypted PDFs (`unlock_pdf`, `get_pdf_unlock_status`, `lock_pdf`); password tool arguments are refused before any work;
- optional, explicitly configured local OCR proposals (macOS Vision or Tesseract) with source replay, offline review and resumable multipage jobs, visible to content-only hosts; OCR stays off and undiscoverable until configured;
- more complete table recovery in `convert_pdf_to_markdown` (tight grids, leading captions, thin filled rules, opt-in headerless grids) and draft three-rule tables behind `emit_table_proposals`;
- source-linked evidence review, append-only corrections and atomic batch verification in extraction workspaces;
- MCP App workspace entrypoints with bounded host-PDF import and conflict-safe save-back;
- safer CSV export, URL downloads and Lumin tool annotations; direct Lumin API calls identify PDF Tools;
- `@modelcontextprotocol/server` 2.0.0 to 2.4.0 and `zod` 4.4.3 to 4.6.7 (#236).

PDF Tools remains local-first. It still bundles no OCR engine, and this release makes no public benchmark or competitor-superiority claim.
